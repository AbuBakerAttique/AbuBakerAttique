## 🚀 Key Projects

> ### 🎯 [AI Interview Coach](https://github.com/AbuBakerAttique/AI-Interview-Coach) &nbsp;·&nbsp; Real-Time Multi-Modal Analysis System &nbsp; `2026`
> Engineered a multi-modal AI pipeline with **4 custom models** for real-time interview analysis using webcam and microphone input.
>
> | Module | Dataset / Method | Architecture | Result |
> |---|---|---|:---:|
> | Speech Confidence | RAVDESS, 2,880 audio files, MFCC | CNN + LSTM | **93.4%** |
> | Facial Expression | FER2013, 28,821 images | Custom CNN | **75.5%** |
> | Posture Analysis | MediaPipe landmarks, 4,794 samples | Neural Network | **97.3%** |
> | Eye Contact | OpenCV Haar Cascade | Rule-based | Real-time |
>
> Built a score-fusion layer that combines model outputs into a final confidence score with grade and actionable feedback.
>
> **Stack:** `Python` `PyTorch` `MediaPipe` `OpenCV` `Librosa` `Flask` `ReactJS`

<br/>

> ### 💪 [AI Gym Rep Counter & Form Analyzer](https://github.com/AbuBakerAttique/Gym-Project) &nbsp; `2026`
> Built a real-time computer-vision fitness tracker using **MediaPipe Pose** to count reps and detect form errors across **6 exercises** without paid APIs.
>
> Engineered a NumPy-based joint-angle calculation engine and state-machine rep counter using exercise-specific elbow, knee, and hip thresholds. Added phone-as-camera mode through MediaPipe.js with self-signed HTTPS, plus a Three.js 3D form guide and real-time voice feedback.
>
> **Stack:** `Python` `MediaPipe` `NumPy` `Three.js` `Web Speech API`

<br/>

> ### 📰 [Fake News Detector](https://fake-news-demo.streamlit.app/) &nbsp;·&nbsp; Explainable AI Web Application &nbsp; `2026`
> Built a fake news detection web app that classifies articles as **Fake** or **Real** using TF-IDF and machine learning models.
>
> Added LIME explanations, model comparison, word cloud visualisations, and statistical writing-style analysis to detect patterns in sentence structure, vocabulary usage, and formality.
>
> **Stack:** `Python` `Flask` `Streamlit` `Scikit-learn` `NLTK` `LIME`

<br/>

> ### 🌿 Plant Disease Detection System &nbsp;·&nbsp; AI + Web App &nbsp; `2024`
> Developed a CNN model to classify plant-leaf diseases from images and served it through a backend inference API for real-time predictions.
>
> Built a responsive full-stack web app with image preprocessing and confidence scoring for non-technical users.
>
> **Stack:** `Python` `TensorFlow` `CNN` `Flask` `REST API`

<br/>

> ### 🤟 Mute Motion &nbsp;·&nbsp; AI Sign-Language to Text &nbsp; `2023 – 2024`
> Built an AI-driven sign-language recognition system to support communication between sign-language and non-sign-language users.
>
> Implemented a React Native frontend with Firebase backend for real-time interaction.
>
> **Stack:** `React Native` `Firebase` `Computer Vision` `Deep Learning`
