## 🚀 Featured Projects

### 🎯 [AI Interview Coach](https://github.com/AbuBakerAttique/AI-Interview-Coach) — Real-Time Multi-Modal Interview Analysis *(2026)*

> A production-level AI system that analyzes interview performance in real time using **4 custom deep learning models trained from scratch** — evaluating speech, facial expression, posture, and eye contact simultaneously, then fusing them into a single confidence score with actionable feedback.

| Model | Dataset | Architecture | Accuracy |
|---|---|---|:---:|
| Speech Confidence | RAVDESS (2,880 audio files) | CNN + LSTM (MFCC) | **93.40%** |
| Facial Expression | FER2013 (28,821 images) | Custom CNN | **75.54%** |
| Posture Scorer | MediaPipe landmarks (4,794 samples) | Neural Network | **97.29%** |
| Eye Contact | OpenCV Haar Cascade | Rule-based | — |

**Stack:** `Python` · `PyTorch` · `MediaPipe` · `OpenCV` · `Librosa` · `Flask` · `ReactJS`

### 💪 [AI Gym Rep Counter & Form Analyzer](https://github.com/AbuBakerAttique/Gym-Project) *(2026)*

> A real-time computer-vision fitness tracker using MediaPipe Pose — counts reps and detects form errors across **6 exercises** with no paid APIs.

- Joint-angle calculation engine (NumPy) with a state-machine rep counter tracking elbow, knee & hip angles
- Phone-as-camera mode via MediaPipe.js with self-signed HTTPS for live mobile pose detection
- 3D animated form guide (Three.js) + real-time voice feedback (Web Speech API)

**Stack:** `Python` · `MediaPipe` · `NumPy` · `Three.js` · `Web Speech API`
