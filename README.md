### 🎯 [AI Interview Coach](https://github.com/AbuBakerAttique/AI-Interview-Coach) — Real-Time Multi-Modal Interview Analysis
 
> A production-level AI system that analyzes interview performance in real time using **4 custom deep learning models** trained from scratch — evaluating speech confidence, facial expressions, body posture, and eye contact simultaneously via webcam and microphone.
 
| Model | Dataset | Architecture | Accuracy |
|---|---|---|---|
| Speech Confidence | RAVDESS (2,880 audio files) | CNN + LSTM | **93.40%** |
| Facial Expression | FER2013 (28,821 images) | Custom CNN | **75.54%** |
| Posture Scorer | MultiPosture (4,794 samples) | Neural Network | **97.29%** |
| Eye Contact | OpenCV + Geometric rules | Rule-based | — |
 
**Stack:** Python · PyTorch · MediaPipe · OpenCV · Librosa · Flask · ReactJS
