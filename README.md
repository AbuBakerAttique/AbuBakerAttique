### 📊 [FinMind AI](https://github.com/AbuBakerAttique/FinMind-AI) · Private Financial Document Intelligence

A local-first **RAG application** for analysing financial reports with semantic retrieval, page citations, structured LLM extraction, and deterministic financial calculations.

<p align="center">
  <a href="https://github.com/AbuBakerAttique/FinMind-AI">
    <img width="90%" src="https://raw.githubusercontent.com/AbuBakerAttique/FinMind-AI/main/docs/images/finmind-dashboard.png" alt="FinMind AI dashboard" />
  </a>
</p>

**Engineering highlights:** PDF ingestion, overlapping chunks, 768-dimensional embeddings, Qdrant vector search, Ollama models, cited answers, Pydantic validation, Python `Decimal` calculations, Docker persistence, health monitoring, and automated tests.

**Stack:** `Python` `FastAPI` `React` `Vite` `Ollama` `Qdrant` `Docker` `Pydantic` `PyPDF` `Pytest`

---

### 🎯 [AI Interview Coach](https://github.com/AbuBakerAttique/AI-Interview-Coach) · Multimodal Analysis

Real-time interview analysis using four custom modules for speech confidence, facial expression, posture, and eye contact. A score-fusion layer combines the model outputs into actionable feedback.

**Results:** Speech confidence **93.4%** · Posture analysis **97.3%** · Facial expression **75.5%**

**Stack:** `Python` `PyTorch` `MediaPipe` `OpenCV` `Librosa` `Flask` `ReactJS`

---

### 💪 [AI Gym Rep Counter & Form Analyzer](https://github.com/AbuBakerAttique/Gym-Project)

Real-time computer-vision fitness tracker that counts repetitions and detects form errors across six exercises using pose landmarks, joint-angle calculations, and exercise-specific state machines.

**Stack:** `Python` `MediaPipe` `NumPy` `Three.js` `Web Speech API`

---

### 📰 [Fake News Detector](https://github.com/AbuBakerAttique/fake-news-project) · [Live Demo](https://fake-news-demo.streamlit.app/)

Classifies articles using TF-IDF and machine-learning models, with LIME explanations, model comparison, word-cloud visualisations, and writing-style analysis.

**Stack:** `Python` `Scikit-learn` `NLTK` `LIME` `Flask` `Streamlit`
